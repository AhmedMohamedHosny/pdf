✅ Supported Formats & Real Capabilities

  • PDF Manipulation (Local): Merge, Split, Reorder, Rotate, Delete/Duplicate Pages, Add Watermark, Page Numbers, Headers/Footers, Signature Image, Metadata Edit.
  • PDF Conversion (Local): PDF → JPG/PNG (per page or ZIP), PDF → TXT, PDF → DOCX (text structure), Images → PDF, TXT → PDF, HTML → PDF.
  • Word & Excel (Local): DOCX → HTML/TXT/PDF (via Mammoth), TXT → DOCX, XLSX/XLS ⇄ CSV/JSON/HTML/PDF (via SheetJS).
  • OCR Vision (Local): Scanned Images/PDFs → Editable Text via Tesseract.js (English & Arabic).
  • Archives (Local): Create ZIP from files/folders, Inspect & Extract ZIP with Zip-Slip & ratio protection.

⚠️ Known Technical Limitations (Transparency)

  • PDF to DOCX Layout: Extracts real text paragraphs into a valid Word file, but complex multi-column graphic layouts may not match 1:1 without a server desktop publisher.
  • Legacy Binary Office (.doc / .ppt): Modern `.docx` and `.xlsx` work locally; legacy 97-2003 binary files require a headless LibreOffice backend worker.
  • PDF Compression: Re-samples page streams. Already-optimized text-only PDFs may not shrink further; AhmedPdf alerts you if the output is larger.
  • Encrypted PDFs: Password-protected PDFs require the owner/user password before pages can be extracted or modified.
ZERO-TRUST SECURITY ARCHITECTURE

Privacy Policy & Security Guarantees

How AhmedPdf protects your documents against unauthorized access and malicious payloads.

1. Local-First Processing Guarantee

By default, all PDF merging, splitting, organizing, image conversion, DOCX/XLSX parsing, and ZIP archiving happen 100% locally inside your browser's memory and IndexedDB. Your documents never leave your device unless you explicitly configure and trigger an external cloud/worker endpoint.

2. Magic-Byte File Signature Verification

AhmedPdf never trusts file extensions alone. Every uploaded file is inspected at the binary header level (e.g., %PDF-, PK\x03\x04, \xFF\xD8\xFF, \x89PNG) to reject disguised executables or corrupted payloads.

3. Archive Extraction Protection (Zip-Slip & Zip-Bomb Guards)

When inspecting or extracting ZIP archives, AhmedPdf sanitizes all entry paths to block directory traversal (../), enforces a strict maximum entry count, monitors uncompressed size ceilings, and never executes extracted files.
